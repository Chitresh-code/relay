# Relay frontend

Vite + React + TypeScript SPA. See [../docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md) for the
session/streaming model and [../CLAUDE.md](../CLAUDE.md) for repo conventions.

```
npm install
npm run dev
```

`VITE_API_BASE_URL` (see `.env.example`) points at the backend's `/chat` endpoint.
